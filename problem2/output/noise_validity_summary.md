# noise_floor 有效性检验结论（第一阶段）

- 判定：**无效/口径不匹配**
- Δ10 = MAE(N1)−MAE(N0) = +0.1057，95%配对Bootstrap CI=[+0.0995, +0.1122]，P(Δ>0)=1.000
- N1 在 0/5 折优于 N0；分终端 grouped-CV：N0=0.9159 vs N1=0.9138
- NS 随机打乱噪声 mae 中位=0.8364；真实噪声 N1=0.8617（30 次打乱中 30 次不优于 N1）
- 排序翻转率 R_flip(N0↔N1)：总体=0.0677，终端内=0.0653，终端间=0.0689
- NC 固定噪声自检：与 N0 逐样本预测一致 = **True**（§9.3 要求必须为 True）

## 依据

- 整体 Spearman：logλ1↔MCS=0.793，noise_floor↔MCS=0.647，logλ1↔noise_floor=0.680
- 分终端 noise_floor↔MCS 方向是否与整体一致：True
- λ1/σ² 与 MCS 相关（0.749）低于 λ1 与 MCS 相关（0.793），说明除以样本级噪声底会破坏有序结构。

## 决策

判定为无效/口径不匹配：主模型固定 θ=0（输入称'主特征模态信道增益'，不称 SINR），θ=1/θ=0.5 作为噪声敏感性结果报告。进入第二阶段尺度放缩 + 五核嵌套比较。
