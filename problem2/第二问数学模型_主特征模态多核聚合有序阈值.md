# 第二问数学模型：主特征模态 SINR + 多核聚合 + 有序阈值速率估计模型

## 1. 问题重述

问题 2 要求利用完备数据集 A 中的 MIMO 信道矩阵

\[
H\in \mathbb C^{2\times 4\times 122}
\]

以及关闭 TxBF 条件下对应的实际传输速率（MCS 标签），提出一种新的速率估计模型，并用于预测不完备数据集 B 中的传输速率。

与问题 1 不同，问题 2 不再要求固定采用 EESM 框架，因此可以重新设计：

\[
H
\longrightarrow
\text{信道质量特征}
\longrightarrow
\text{跨载波聚合}
\longrightarrow
\text{MCS 映射}
\]

的完整链路。

---

## 2. 数据特性与建模出发点

对训练集 A 的分析表明，对于同一样本的 122 个载波，

\[
\|H_k\|_F^2
\]

几乎完全一致，其相对标准差达到机器精度量级。因此，问题 1 中基于

\[
\gamma_k=\frac{\|H_k\|_F^2}{\sigma_n^2}
\]

构造的 EESM 会发生退化：不同载波上的输入几乎相同，核函数无法进一步提取频域差异。

但是，尽管

\[
\|H_k\|_F^2
=
\lambda_{1,k}+\lambda_{2,k}
\]

近似保持不变，两个空间特征模态

\[
\lambda_{1,k},\lambda_{2,k}
\]

仍可能随载波发生变化。

因此问题 2 的核心思想是：

\[
\boxed{
\text{不再只使用信道总功率，而是利用 }H_kH_k^H\text{ 的主特征模态信息。}
}
\]

---

## 3. 模型总体框架

对第 \(n\) 个样本、第 \(k\) 个载波，定义 MIMO 信道矩阵

\[
H_{n,k}\in\mathbb C^{2\times 4},
\qquad
k=1,\ldots,K,
\]

其中

\[
K=122.
\]

第二问的整体模型为

\[
\boxed{
H_{n,k}
\rightarrow
H_{n,k}H_{n,k}^H
\rightarrow
\lambda_{1,n,k}
\rightarrow
x_{n,k}
\rightarrow
\text{多核聚合}
\rightarrow
x_{n,\mathrm{eff}}
\rightarrow
\text{有序阈值模型}
\rightarrow
\widehat{\mathrm{MCS}}_n.
}
\]

其中：

- \(\lambda_{1,n,k}\)：第 \(k\) 个载波对应的最大空间特征值；
- \(x_{n,k}\)：主特征模态 SINR；
- \(x_{n,\mathrm{eff}}\)：通过不同核函数聚合后的等效信道质量指标；
- \(\widehat{\mathrm{MCS}}_n\)：最终预测的 MCS 档位。

---

## 4. 第一层：MIMO 空间特征提取

### 4.1 构造 Gram 矩阵

对每一个载波，定义

\[
G_{n,k}
=
H_{n,k}H_{n,k}^H.
\]

由于

\[
H_{n,k}\in\mathbb C^{2\times4},
\]

所以

\[
G_{n,k}\in\mathbb C^{2\times2}.
\]

记

\[
G_{n,k}
=
\begin{pmatrix}
a_{n,k} & b_{n,k}\\
b_{n,k}^{*} & c_{n,k}
\end{pmatrix}.
\]

定义

\[
t_{n,k}
=
\operatorname{tr}(G_{n,k})
=
a_{n,k}+c_{n,k}
=
\|H_{n,k}\|_F^2,
\]

以及

\[
d_{n,k}
=
\det(G_{n,k})
=
a_{n,k}c_{n,k}-|b_{n,k}|^2.
\]

### 4.2 特征值闭式计算

\[
\lambda_{1,n,k}+\lambda_{2,n,k}=t_{n,k},
\qquad
\lambda_{1,n,k}\lambda_{2,n,k}=d_{n,k}.
\]

因此

\[
\boxed{
\lambda_{1,n,k}
=
\frac{
t_{n,k}
+
\sqrt{t_{n,k}^{2}-4d_{n,k}}
}{2}
}
\]

和

\[
\boxed{
\lambda_{2,n,k}
=
\frac{
t_{n,k}
-
\sqrt{t_{n,k}^{2}-4d_{n,k}}
}{2}.
}
\]

其中

\[
\lambda_{1,n,k}\geq \lambda_{2,n,k}\geq0.
\]

由于矩阵仅为 \(2\times2\)，可以直接使用上述闭式公式，无需逐载波进行 SVD。

---

## 5. 主特征模态 SINR

问题 1 中使用

\[
\|H_{n,k}\|_F^2
=
\lambda_{1,n,k}+\lambda_{2,n,k}
\]

衡量信道总增益，但该指标无法区分不同的空间能量分配方式。

因此第二问选取最大特征值 \(\lambda_1\) 构造新的信道质量指标。

设样本 \(n\) 的底噪为 \(NF_n\) dBm，按照与问题 1 一致的口径：

\[
\boxed{
\sigma_n^2
=
N_{\mathrm{RX}}
\cdot
10^{NF_n/10},
}
\]

其中

\[
N_{\mathrm{RX}}=2.
\]

定义第 \(k\) 个载波上的主特征模态 SINR：

\[
\boxed{
x_{n,k}
=
\gamma_{n,k}^{\mathrm{eig}}
=
\frac{\lambda_{1,n,k}}
{\sigma_n^2}.
}
\]

建议在论文中将其称为“主特征模态 SINR”或“接收合并 SINR 代理量”。

---

## 6. 第二层：多核跨载波聚合

统一定义一般核聚合形式：

\[
\boxed{
x_{n,\mathrm{eff}}^{(\Phi)}
=
\Phi^{-1}
\left[
\sum_{k=1}^{K}
p_k
\Phi(x_{n,k})
\right].
}
\]

为保证不同核函数之间的比较公平，统一采用等权：

\[
\boxed{
p_k=\frac1K=\frac1{122}.
}
\]

因此

\[
\boxed{
x_{n,\mathrm{eff}}^{(\Phi)}
=
\Phi^{-1}
\left[
\frac1{122}
\sum_{k=1}^{122}
\Phi(x_{n,k})
\right].
}
\]

本问选取以下五组核函数进行比较。

---

## 7. 五类候选核函数

### 7.1 K1：线性核

\[
\boxed{
\Phi_{\mathrm{lin}}(x)=x.
}
\]

则

\[
\boxed{
x_{n,\mathrm{eff}}^{(\mathrm{lin})}
=
\frac1K
\sum_{k=1}^{K}
x_{n,k}.
}
\]

即普通算术平均。

---

### 7.2 K2：香农容量核

\[
\boxed{
\Phi_{\mathrm{cap}}(x)
=
\log_2(1+x).
}
\]

于是

\[
\boxed{
x_{n,\mathrm{eff}}^{(\mathrm{cap})}
=
2^{
\frac1K
\sum_{k=1}^{K}
\log_2(1+x_{n,k})
}
-1.
}
\]

该核先把每个载波的 SINR 转换为容量型度量，再进行平均。

---

### 7.3 K3：EESM 指数核

\[
\boxed{
x_{n,\mathrm{eff}}^{(\mathrm{EESM})}
=
-\beta
\ln
\left[
\frac1K
\sum_{k=1}^{K}
\exp
\left(
-\frac{x_{n,k}}{\beta}
\right)
\right].
}
\]

其中

\[
\beta>0
\]

由训练集交叉验证确定。

该核更强调较弱载波。

---

### 7.4 K4：幂函数核

\[
\boxed{
\Phi_q(x)=x^q.
}
\]

聚合结果为

\[
\boxed{
x_{n,\mathrm{eff}}^{(q)}
=
\left[
\frac1K
\sum_{k=1}^{K}
x_{n,k}^{q}
\right]^{1/q}.
}
\]

推荐初始搜索：

\[
\boxed{
q\in
\{-2,-1,-0.5,0.5,1,2\}.
}
\]

其中 \(q<1\) 更偏向较弱载波，\(q>1\) 更偏向较强载波。

---

### 7.5 K5：正指数核

\[
\boxed{
\Phi_+(x)=\exp(x/\beta).
}
\]

于是

\[
\boxed{
x_{n,\mathrm{eff}}^{(+)}
=
\beta
\ln
\left[
\frac1K
\sum_{k=1}^{K}
\exp
\left(
\frac{x_{n,k}}{\beta}
\right)
\right].
}
\]

其中 \(\beta>0\) 通过交叉验证确定。

该核更强调较强载波，与 EESM 形成对照。

---

## 8. 五类核函数的统一比较原则

五种候选模型共同使用：

\[
x_{n,k}
=
\frac{\lambda_{1,n,k}}{\sigma_n^2}
\]

作为载波级输入。

不同模型仅改变核函数 \(\Phi\)。

因此保证：

\[
\boxed{
\text{相同底层特征}
+
\text{相同载波权重}
+
\text{相同 MCS 映射}
+
\text{仅改变核函数}.
}
\]

这样最终性能差异可以直接归因于不同的跨载波聚合机制。

---

## 9. 第三层：有序阈值速率映射

设所有可能的 MCS 档位为

\[
m_0<m_1<\cdots<m_{L-1}.
\]

将标签编码为

\[
c_n\in\{0,1,\ldots,L-1\}.
\]

对任意核函数产生的聚合特征

\[
z_n=x_{n,\mathrm{eff}}^{(\Phi)},
\]

建立单调阶梯映射。

设阈值为

\[
\boxed{
\tau_1\leq\tau_2\leq\cdots\leq\tau_{L-1}.
}
\]

则预测类别为

\[
\boxed{
\hat c(z)
=
\sum_{j=1}^{L-1}
I(z>\tau_j).
}
\]

最终恢复 MCS：

\[
\boxed{
\widehat{\mathrm{MCS}}
=
m_{\hat c}.
}
\]

---

## 10. 阈值学习：加权中位数等渗回归

给定训练样本

\[
\{(z_n,c_n)\}_{n=1}^{N},
\]

采用单调约束下的加权绝对损失：

\[
\boxed{
\min_{f\ \mathrm{nondecreasing}}
\sum_{n=1}^{N}
\omega_{c_n}
\left|
c_n-f(z_n)
\right|.
}
\]

若不开启类别权重：

\[
\omega_l=1.
\]

若考虑类别不平衡：

\[
\boxed{
\omega_l
=
\frac{N}{L N_l},
}
\]

其中 \(N_l\) 为第 \(l\) 类样本数量。

使用 PAVA 求解单调阶梯函数，并由阶梯函数提取阈值

\[
\tau_1,\ldots,\tau_{L-1}.
\]

---

## 11. 参数选择与交叉验证

固定：

- 5-fold stratified CV；
- seed = 42；
- 所有核函数使用完全相同的折分；
- 所有核函数使用相同的有序阈值模型；
- 载波权重固定为 \(1/122\)。

参数：

- 线性核：无参数；
- 容量核：无参数；
- EESM 核：搜索 \(\beta_{\mathrm{EESM}}\)；
- 幂函数核：搜索 \(q\)；
- 正指数核：搜索 \(\beta_+\)。

---

## 12. 模型评价指标

### 12.1 Accuracy

\[
\boxed{
\mathrm{Accuracy}
=
\frac1N
\sum_{n=1}^{N}
I(\hat c_n=c_n).
}
\]

### 12.2 Ordinal MAE

\[
\boxed{
\mathrm{MAE}_{\mathrm{ord}}
=
\frac1N
\sum_{n=1}^{N}
|\hat c_n-c_n|.
}
\]

将其作为主评价指标。

### 12.3 Acc\(_{\pm1}\)

\[
\boxed{
\mathrm{Acc}_{\pm1}
=
\frac1N
\sum_{n=1}^{N}
I(|\hat c_n-c_n|\le1).
}
\]

---

## 13. 模型选择规则

对五类候选核函数及其参数进行相同的 5-fold CV。

主选择规则：

\[
\boxed{
\Phi^*
=
\arg\min_{\Phi}
\mathrm{MAE}_{\mathrm{ord}}^{CV}.
}
\]

若多个模型的 MAE 接近，则依次比较：

1. Accuracy；
2. Acc\(_{\pm1}\)；
3. 模型复杂度。

优先选择结构更简单、解释更清晰的模型。

---

## 14. 与问题 1 的关系

问题 1 的核心特征：

\[
\gamma_F
=
\frac{\|H\|_F^2}{\sigma_n^2}
=
\frac{\lambda_1+\lambda_2}{\sigma_n^2}.
\]

问题 2 改为：

\[
\boxed{
\gamma_{\mathrm{eig}}
=
\frac{\lambda_1}{\sigma_n^2}.
}
\]

因此核心改进为：

\[
\boxed{
\text{总信道能量}
\longrightarrow
\text{主空间特征模态}.
}
\]

在此基础上进一步比较：

\[
\boxed{
\text{线性平均}
,\;
\text{容量型聚合}
,\;
\text{弱载波偏置}
,\;
\text{广义幂平均}
,\;
\text{强载波偏置}.
}
\]

## 15. 算法设计阶段建议流程

### Stage 0：数据诊断

计算并保存

\[
\lambda_{1,n,k},\quad
\lambda_{2,n,k},\quad
x_{n,k}
\]

以及跨载波均值、标准差、相对标准差。

### Stage 1：生成五类聚合特征

得到

\[
z_{\mathrm{lin}},
z_{\mathrm{cap}},
z_{\mathrm{EESM}},
z_{\mathrm{pow}},
z_{+}.
\]

### Stage 2：参数 CV

搜索

\[
\beta_{\mathrm{EESM}},
\qquad
q,
\qquad
\beta_+.
\]

### Stage 3：有序阈值拟合

对每一种候选特征使用完全相同的 PAVA 有序模型。

### Stage 4：模型比较

输出：

- Accuracy；
- Ordinal MAE；
- Acc\(_{\pm1}\)；
- 最优核函数；
- 最优核参数。

### Stage 5：全量训练与 Valid 预测

使用训练集 A 全量重新拟合最终模型，并预测数据集 B。

## 16. 论文中建议强调的创新点

### 创新点 1：空间特征提取

由

\[
\|H\|_F^2
\]

改为利用

\[
HH^H
\]

的主特征模态

\[
\lambda_1,
\]

从而恢复第一问中被总功率压缩所丢失的 MIMO 空间结构信息。

### 创新点 2：数据驱动核函数选择

新的主特征模态 SINR 在不同载波间存在差异，因此跨载波聚合不再退化。

比较：

- 算术平均；
- 容量型聚合；
- 弱载波主导聚合；
- 广义幂平均；
- 强载波主导聚合；

并通过交叉验证确定最符合实际 MCS 数据的核函数。

因此模型可概括为：

\[
\boxed{
\text{MIMO 主特征模态提取}
+
\text{多核载波聚合}
+
\text{有序阈值速率估计}.
}
\]
