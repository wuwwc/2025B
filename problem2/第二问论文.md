# 一、第二问论文写作大纲

建议在正式论文中将问题二紧接问题一，组织为：

## 5 问题二：基于主特征模态与多核聚合的有序速率估计模型

### 5.1 问题分析与问题一模型局限

重点说明：

- 问题二仍研究关闭 TxBF 情形，数据对象、训练标签与问题一一致；
- 问题一采用 \(\|H_k\|_F^2\) 构造载波级 SINR，但数据分析发现同一样本 122 个载波上的 \(\|H_k\|_F^2\) 几乎完全一致；
- 因而问题一中的 EESM 在该特征上近似退化为恒等映射，参数 \(\beta\) 难以识别；
- 这并不意味着信道矩阵本身没有载波差异，而是 Frobenius 范数压缩后丢失了 MIMO 空间结构信息；
- 问题二因此从 \(H_kH_k^H\) 的特征值结构中提取新的载波级特征，并重新研究跨载波聚合方式。

### 5.2 主特征模态 SINR 构造

- 构造
  \[
  G_k=H_kH_k^H;
  \]
- 利用 \(2\times2\) Hermitian 矩阵闭式公式计算最大特征值 \(\lambda_{1,k}\)；
- 构造主特征模态 SINR
  \[
  x_k=\lambda_{1,k}/P_n;
  \]
- 解释其相对 \(\|H_k\|_F^2/P_n\) 的信息增益。

### 5.3 多核等效信道质量模型

统一写为

\[
x_{\mathrm{eff}}^{(\Phi)}
=
\Phi^{-1}
\left[
\frac1K\sum_{k=1}^{K}\Phi(x_k)
\right].
\]

比较五种核函数：

1. 线性核；
2. 香农容量核；
3. EESM 指数核；
4. 幂函数核；
5. 正指数核。

强调：

- 五种模型底层特征、载波权重、MCS 映射完全一致；
- 仅改变核函数，因此可以公平比较不同载波聚合机制。

### 5.4 有序阈值速率映射

复用问题一已经验证有效的有序思想：

\[
x_{\mathrm{eff}}
\rightarrow
\widehat{\mathrm{MCS}}.
\]

为了避免重复，正文只简述单调阶梯映射和 PAVA/有序拟合思想，并明确“求解与评价协议沿用问题一”。

### 5.5 模型求解与核函数选择

- 5-fold 分层交叉验证；
- 线性核、容量核无额外参数；
- EESM 搜索 \(\beta_-\)；
- 幂函数核搜索 \(q\)；
- 正指数核搜索 \(\beta_+\)；
- 以 Ordinal MAE 为主指标；
- 平手时依次比较 Accuracy、\(\mathrm{Acc}_{\pm1}\) 和模型复杂度。

### 5.6 结果与分析

建议安排：

- 五类核函数交叉验证性能对比表；
- EESM \(\beta_-\)、幂核 \(q\)、正指数 \(\beta_+\) 的参数敏感性曲线；
- 最优核聚合特征与 MCS 的分布图；
- 问题一主模型与问题二最优模型对比表；
- 必要时增加误差分布或混淆矩阵。

### 5.7 验证集 B 预测

使用训练集 A 全量重拟合最优核函数和有序阈值模型，预测 B 中指定样本的 MCS。

### 5.8 本问小结

总结：

- 问题二不是简单更换 EESM 参数，而是先更换信道特征；
- 再通过多核比较寻找更合适的跨载波聚合机制；
- 最终保留 MCS 的有序结构，实现与问题一自然衔接。

# 二、第二问论文正文草稿

# 5 问题二：基于主特征模态与多核聚合的有序速率估计模型

## 5.1 问题分析与问题一模型局限

问题二与问题一使用相同的关闭 TxBF 数据，但不再限定采用 EESM 模型，而要求根据 MIMO 信道矩阵 \(H_{2\times4\times122}\) 与实际传输速率标签重新构造速率估计方法。

问题一建立了

\[
H_k
\longrightarrow
\frac{\|H_k\|_F^2}{P_n}
\longrightarrow
\mathrm{EESM}
\longrightarrow
\widehat{\mathrm{MCS}}
\]

的物理层抽象链路。其中，Frobenius 范数

\[
\|H_k\|_F^2
\]

描述第 \(k\) 个载波上 MIMO 信道矩阵的总能量。

然而，对训练集 A 的进一步分析发现：对于同一条样本，122 个载波上的

\[
\|H_k\|_F^2
\]

几乎完全一致，其相对标准差仅为机器精度量级。由此，问题一中的载波级 SINR

\[
\gamma_k
=
\frac{\|H_k\|_F^2}{P_n}
\]

在同一样本内部近似满足

\[
\gamma_1
=
\gamma_2
=
\cdots
=
\gamma_{122}.
\]

对于一般的等效 SINR 映射

\[
\gamma_{\mathrm{eff}}
=
\Phi^{-1}
\left[
\frac1K\sum_{k=1}^{K}\Phi(\gamma_k)
\right],
\]

若所有 \(\gamma_k\) 相同，则必有

\[
\gamma_{\mathrm{eff}}=\gamma_k.
\]

因此，问题一中基于 Frobenius 范数构造的 ESM 层在当前数据上近似退化，其核参数难以通过载波间差异得到有效识别。

需要指出的是，这种退化只说明

\[
\|H_k\|_F^2
\]

不足以反映载波间的有效差异，并不意味着原始矩阵 \(H_k\) 本身完全相同。事实上，

\[
\|H_k\|_F^2
=
\lambda_{1,k}+\lambda_{2,k},
\]

其中 \(\lambda_{1,k},\lambda_{2,k}\) 为 \(H_kH_k^H\) 的两个非负特征值。即使总和基本不变，不同载波上的空间能量分配仍可能发生变化。

例如，若两个载波分别满足

\[
(\lambda_1,\lambda_2)=(9,1)
\]

和

\[
(\lambda_1,\lambda_2)=(5,5),
\]

则二者具有相同的

\[
\|H\|_F^2=10,
\]

但主空间模态强度明显不同。

因此，问题二不再沿用“总信道能量”作为唯一信息源，而从 \(H_kH_k^H\) 的谱结构中提取主特征模态，并建立

\[
\boxed{
H_k
\longrightarrow
\lambda_{1,k}
\longrightarrow
x_k
\longrightarrow
x_{\mathrm{eff}}
\longrightarrow
\widehat{\mathrm{MCS}}
}
\]

的新型速率估计框架。

与问题一相比，问题二的改进包含两层：

1. **特征层改进**：由总信道能量 \(\|H_k\|_F^2\) 改为主特征模态 \(\lambda_{1,k}\)；
2. **聚合层改进**：针对新的非平坦载波特征，比较多种核函数，而不再预先固定 EESM。

---

## 5.2 主特征模态 SINR

### 5.2.1 MIMO 空间特征提取

对第 \(j\) 个样本的第 \(k\) 个载波，仍记

\[
H_k^{(j)}
\in
\mathbb C^{2\times4}.
\]

构造接收端 Gram 矩阵

\[
\boxed{
G_k^{(j)}
=
H_k^{(j)}
\left(H_k^{(j)}\right)^H.
}
\]

由于接收天线数为 2，

\[
G_k^{(j)}
\in
\mathbb C^{2\times2}.
\]

记

\[
G_k^{(j)}
=
\begin{pmatrix}
a_{j,k} & b_{j,k}\\
b_{j,k}^* & c_{j,k}
\end{pmatrix}.
\]

定义

\[
t_{j,k}
=
\operatorname{tr}
\left(G_k^{(j)}\right)
=
a_{j,k}+c_{j,k},
\]

\[
d_{j,k}
=
\det
\left(G_k^{(j)}\right)
=
a_{j,k}c_{j,k}
-
|b_{j,k}|^2.
\]

其中

\[
t_{j,k}
=
\left\|H_k^{(j)}\right\|_F^2.
\]

由于 \(G_k^{(j)}\) 为 \(2\times2\) Hermitian 半正定矩阵，其两个特征值可以直接写为

\[
\boxed{
\lambda_{1,j,k}
=
\frac{
t_{j,k}
+
\sqrt{t_{j,k}^2-4d_{j,k}}
}{2},
}
\]

\[
\boxed{
\lambda_{2,j,k}
=
\frac{
t_{j,k}
-
\sqrt{t_{j,k}^2-4d_{j,k}}
}{2},
}
\]

且

\[
\lambda_{1,j,k}
\ge
\lambda_{2,j,k}
\ge0.
\]

这一闭式表达避免了对每个载波重复进行完整 SVD，同时保留了 MIMO 空间模态信息。

### 5.2.2 主特征模态信道质量

问题一使用

\[
\lambda_{1,j,k}+\lambda_{2,j,k}
\]

描述总信道能量，而问题二重点关注其中最强空间模态

\[
\lambda_{1,j,k}.
\]

底噪处理、训练样本筛选以及 MCS 有序编码均沿用问题一。记第 \(j\) 个样本的线性噪声功率为

\[
P_n^{(j)}.
\]

定义载波级主特征模态 SINR 为

\[
\boxed{
x_{j,k}
=
\gamma_{j,k}^{(\mathrm{eig})}
=
\frac{
\lambda_{1,j,k}
}{
P_n^{(j)}
}.
}
\]

该指标反映主空间特征方向上的相对信道质量。与问题一的

\[
\gamma_{j,k}^{(F)}
=
\frac{
\lambda_{1,j,k}+\lambda_{2,j,k}
}{
P_n^{(j)}
}
\]

相比，\(x_{j,k}\) 不再只保留特征值总和，因此能够区分总能量接近但空间能量分配不同的信道状态。

需要强调的是，本文将 \(x_{j,k}\) 作为**主特征模态 SINR 代理量**使用，其主要作用是构造具有明确物理意义的载波级信道质量特征，而不将其等同于某一具体接收机实现下的精确后处理 SINR。

---

## 5.3 多核等效信道质量模型

与问题一不同，新的主特征模态 SINR

\[
x_{j,1},x_{j,2},\ldots,x_{j,122}
\]

在载波间不再近似完全相同，因此非线性跨载波聚合重新具有实际意义。

为公平比较不同聚合机制，统一定义

\[
\boxed{
z_j^{(\Phi)}
=
\Phi^{-1}
\left[
\frac1K
\sum_{k=1}^{K}
\Phi(x_{j,k})
\right],
\qquad K=122.
}
\]

各载波均采用等权

\[
p_k=\frac1K,
\]

从而所有候选模型只有核函数 \(\Phi\) 不同，底层载波特征及后续 MCS 映射保持完全一致。

本文比较以下五类核函数。

### 5.3.1 线性核

取

\[
\Phi_{\mathrm{lin}}(x)=x,
\]

得到

\[
\boxed{
z_j^{(\mathrm{lin})}
=
\frac1K
\sum_{k=1}^{K}x_{j,k}.
}
\]

该模型认为所有载波对整体链路质量具有等权线性贡献，是多核比较中的基础模型。

---

### 5.3.2 香农容量核

根据题面给出的高斯白噪声信道容量度量，取

\[
\Phi_{\mathrm{cap}}(x)
=
\log_2(1+x).
\]

其逆变换为

\[
\Phi_{\mathrm{cap}}^{-1}(u)
=
2^u-1,
\]

因此

\[
\boxed{
z_j^{(\mathrm{cap})}
=
2^{
\frac1K
\sum_{k=1}^{K}
\log_2(1+x_{j,k})
}
-1.
}
\]

该核首先将载波 SINR 转化为容量型度量再进行平均，能够体现链路容量随 SINR 对数增长的特征，并抑制极大 SINR 对聚合结果的线性放大。

---

### 5.3.3 EESM 指数核

为了检验实际 MCS 是否受到低质量载波更强的限制，采用指数型聚合

\[
\boxed{
z_j^{(-)}
=
-\beta_-
\ln
\left[
\frac1K
\sum_{k=1}^{K}
\exp
\left(
-\frac{x_{j,k}}{\beta_-}
\right)
\right],
\qquad
\beta_->0.
}
\]

当 \(\beta_-\) 较小时，该聚合更接近

\[
\min_k x_{j,k},
\]

因此能够突出较弱载波对整体链路质量的影响。

需要说明的是：问题一中 EESM 的退化源于输入 \(\|H_k\|_F^2/P_n\) 在载波间近似完全相同；问题二更换为 \(\lambda_{1,k}/P_n\) 后，输入已经存在实际差异，因此这里重新比较 EESM 是合理的，而不与问题一的退化结论矛盾。

---

### 5.3.4 幂函数核

为建立能够在“弱载波主导”和“强载波主导”之间连续调节的统一模型，取

\[
\Phi_q(x)=x^q.
\]

于是得到广义幂平均

\[
\boxed{
z_j^{(q)}
=
\left[
\frac1K
\sum_{k=1}^{K}
x_{j,k}^{q}
\right]^{1/q}.
}
\]

该模型包含多种典型平均作为特殊情形：

\[
q=1
\Rightarrow
\text{算术平均},
\]

\[
q=-1
\Rightarrow
\text{调和平均},
\]

\[
q\rightarrow0
\Rightarrow
\text{几何平均},
\]

\[
q\rightarrow+\infty
\Rightarrow
\max_kx_{j,k},
\]

\[
q\rightarrow-\infty
\Rightarrow
\min_kx_{j,k}.
\]

因此 \(q\) 的最优取值能够反映实际速率对不同载波质量区域的敏感程度。

---

### 5.3.5 正指数核

为进一步检验高质量载波是否对最终 MCS 具有更强贡献，构造与 EESM 相对的正指数核：

\[
\boxed{
z_j^{(+)}
=
\beta_+
\ln
\left[
\frac1K
\sum_{k=1}^{K}
\exp
\left(
\frac{x_{j,k}}{\beta_+}
\right)
\right],
\qquad
\beta_+>0.
}
\]

当 \(\beta_+\) 较小时，

\[
z_j^{(+)}
\]

更接近

\[
\max_kx_{j,k}.
\]

因此，负指数核与正指数核分别代表“弱载波偏置”和“强载波偏置”，二者的比较能够帮助判断实际 MCS 更依赖链路中的瓶颈载波还是优势载波。

---

## 5.4 有序阈值速率映射

问题一的结果表明，MCS 与信道质量之间具有明显的有序阶梯特征，因此问题二不再重新设计第三层速率映射，而复用问题一已经建立的有序结构。

设某一候选核函数得到第 \(j\) 个样本的等效信道质量

\[
z_j.
\]

将实际出现的 MCS 由小到大记为

\[
m_0<m_1<\cdots<m_L.
\]

设置单调阈值

\[
\tau_1<\tau_2<\cdots<\tau_L,
\]

并定义

\[
\boxed{
\widehat y_j
=
Q_{\boldsymbol\tau}(z_j).
}
\]

即当

\[
\tau_\ell
\le z_j<\tau_{\ell+1}
\]

时，预测

\[
\widehat y_j=m_\ell.
\]

为避免与问题一重复，本问不再展开有序阈值模型的完整推导。其核心仍是利用 MCS 的序数结构，对信道质量与档位索引之间建立单调阶梯映射。

在具体实现中，采用与问题一一致的单调拟合思想，在训练折上根据

\[
(z_j,c(y_j))
\]

求取有序阶梯函数及其阈值。若启用类别权重，则仍采用问题一中的逆频率权重

\[
w_\ell
=
\frac{N}{(L+1)N_\ell}.
\]

这样可以保证问题一和问题二的性能差异主要来自**信道特征与聚合方法的改变**，而非第三层分类器变化。

---

## 5.5 模型求解与核函数选择

### 5.5.1 总体求解框架

五类候选模型共享如下结构：

\[
\boxed{
H_k
\rightarrow
\lambda_{1,k}
\rightarrow
x_k
\rightarrow
z^{(\Phi)}
\rightarrow
Q_{\boldsymbol\tau}
\rightarrow
\widehat{\mathrm{MCS}}.
}
\]

其中：

- 线性核和容量核无额外参数；
- EESM 核含参数 \(\beta_-\)；
- 幂函数核含参数 \(q\)；
- 正指数核含参数 \(\beta_+\)。

因此问题二的模型选择本质上为

\[
\boxed{
\text{核函数选择}
+
\text{核参数标定}
+
\text{有序阈值拟合}.
}
\]

---

### 5.5.2 参数搜索

为避免数值尺度差异，\(\beta_-\) 与 \(\beta_+\) 均在对数尺度上搜索：

\[
\beta_-\in\mathcal B_-,
\qquad
\beta_+\in\mathcal B_+.
\]

实际程序中采用“粗网格 + 局部细化”的方式确定最优参数。

幂函数核首先采用

\[
\boxed{
q\in
\{-2,-1,-0.5,0.5,1,2\}
}
\]

进行初始搜索；若最优值位于网格边界，再向对应方向扩展搜索范围。

对于指数型聚合，为避免计算

\[
\exp(\pm x/\beta)
\]

时出现上溢或下溢，程序采用 `logsumexp` 技巧实现。

---

### 5.5.3 交叉验证与模型选择

为保证与问题一的结果可以直接比较，问题二继续采用相同的 \(K_{\mathrm{cv}}\)-折分层交叉验证，并固定相同随机种子。

对于任一核函数 \(\Phi\) 及其参数 \(\theta\)，第 \(f\) 折验证损失记为

\[
\mathrm{MAE}_{f}^{(\Phi,\theta)}.
\]

定义

\[
\boxed{
CV(\Phi,\theta)
=
\frac1{K_{\mathrm{cv}}}
\sum_{f=1}^{K_{\mathrm{cv}}}
\mathrm{MAE}_{f}^{(\Phi,\theta)}.
}
\]

其中 MAE 仍采用问题一中的 Ordinal MAE。

最优模型由

\[
\boxed{
(\widehat\Phi,\widehat\theta)
=
\arg\min_{\Phi,\theta}
CV(\Phi,\theta)
}
\]

确定。

当不同候选模型的 Ordinal MAE 十分接近时，依次比较：

1. Accuracy；
2. \(\mathrm{Acc}_{\pm1}\)；
3. 模型复杂度与可解释性。

这样既保证预测效果，也避免为了微小数值增益引入不必要的参数。

## 5.8 本问小结

问题一以

\[
\|H_k\|_F^2
\]

描述各载波的总信道能量，并通过 EESM 建立等效 SINR。然而数据分析发现，同一样本不同载波上的 Frobenius 范数几乎完全一致，使得该层面的 ESM 映射近似退化，也表明仅利用总信道能量难以进一步挖掘 CSI 中的有效差异。

因此，问题二从 MIMO 信道矩阵的谱结构出发，通过

\[
G_k=H_kH_k^H
\]

提取最大特征值

\[
\lambda_{1,k},
\]

并构造主特征模态 SINR

\[
x_k=\lambda_{1,k}/P_n.
\]

该特征在保留信道强度信息的同时，引入了第一问中被 Frobenius 范数压缩掉的空间模态信息。

在跨载波聚合层，本文不再预先指定某一种等效映射，而统一比较线性核、容量核、EESM 指数核、幂函数核和正指数核。五类模型共享相同的主特征模态输入、等权载波设置以及有序阈值映射，因此其性能差异能够直接反映不同聚合机制的适用性。

最终，通过与问题一完全一致的交叉验证协议和评价指标确定最优核函数及参数，再使用全部训练数据重拟合模型，对验证集 B 的传输速率进行预测。由此，问题二形成了从“总能量 EESM”到“空间主模态 + 数据驱动核聚合”的自然递进，并保持了与问题一相同的 MCS 有序建模逻辑。
